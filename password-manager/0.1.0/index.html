帮助 · 数据安全

加密方案

开门密码BCrypt（bcryptjs，cost=10，自动加盐）哈希后存盘，只用于校验；磁盘上不存在任何可逆的密码材料。
AES 密钥取上述 BCrypt 密文再做一次 SHA-256，得到 32 字节，即 aes-256-cbc 的密钥（"开门密码经过哈希处理的值"）。
帐号数据整条帐号（标题/用户名/密码/网址/备注/标签）序列化为 JSON 后用 AES-256-CBC + PKCS7 加密，每条独立随机 16 字节 IV。
存储位置Spark 插件私有存储 plugin-data/com.spark.password-manager/db，只有明文骨架 + BCrypt 密文 + 密文块。
完整性解锁时先解校验块，再逐条解 PKCS7；任一环节失败即报「数据损坏」，不会把乱码当密码展示。

无法破解的含义

没有开门密码时，攻击者拿到整份数据也只能看到 BCrypt 哈希与密文。要恢复明文必须先求出开门密码—— 每次尝试都要跑一遍 BCrypt（故意设计得慢），无法用字典批量穷举；而 AES-256 密钥并不落盘，内存中也只在解锁期间存在。 代价是：忘记开门密码无法找回，也没有恢复码。

日常建议

  • 不同站点用不同密码——用「生成」按钮，16 位以上、含符号。
  • 复制密码后 20 秒自动清空剪贴板（可在设置里调整）。
  • 离开电脑前按 Ctrl+L 锁定；也可开启「切换到其它窗口时立即锁定」。
  • 注意大写锁定：密码框旁边会提示 Caps Lock。

本插件为本地工具，不提供云同步。换机迁移请用「导出加密包」。
