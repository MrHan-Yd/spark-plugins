# 密码管家（password-manager）

Spark webview 插件：**本地加密密码保险库**。搜索框输入 `pwd` / `密码管家` / `password` 打开（后面的字会作为初始筛选词）。全程离线——只声明 `clipboard` 一项权限，没有 `net`，不会有任何内容离开本机。

## 数据安全（与实现一一对应）

| 环节 | 做法 |
|------|------|
| 开门密码 | **BCrypt**（cost=10，bcryptjs，自动加盐）哈希后存盘，只用于校验；磁盘上不存在任何可逆的密码材料。超过 72 字节的密码先 SHA-256 归一，避免 BCrypt 静默截断 |
| AES 密钥 | 取上述 BCrypt 密文再做一次 SHA-256 → 32 字节，即 `aes-256-cbc` 的密钥（"开门密码经过哈希处理的值"）。**密钥不落盘**，只在解锁期间驻留内存 |
| 帐号数据 | 整条帐号（标题/用户名/密码/网址/备注/标签/历史）序列化后 **AES-256-CBC + PKCS7** 加密，每条独立随机 16 字节 IV，密文整体 base64 落盘 |
| 落盘内容 | Spark 插件私有存储 `plugin-data/com.spark.password-manager/db`：`pm.meta`（明文骨架 + BCrypt 密文 + 校验块）、`pm.data`（纯 `{iv, ct}`）、`pm.prefs`（主题/自动锁定等非敏感偏好） |
| 完整性 | 解锁先解校验块再解数据，任一失败即报「数据损坏」，不会把乱码当密码展示；解锁错误密码时不留下任何密钥残留 |

**「没有开门密码无法破解」的边界**：拿到整份数据也只能看到 BCrypt 哈希与密文，恢复明文必须**先求出开门密码**——每次尝试都要跑一遍 BCrypt（故意设计得慢）并重算密钥，无法用字典批量穷举。代价是**忘记开门密码无法找回**，也没有恢复码；忘记后只能在开门页「格式化并重建」。

## 功能

- **首次建库**：设置开门密码（**只要求至少 4 位**，不校验大小写/数字/符号，实时显示强度与熵供参考）+ 可选明文提示语；两次输入不一致直接拒绝。
- **解锁**：Caps Lock 提示；连续输错 3 次起逐步冷却；忘记密码 → 格式化重建。
- **帐号管理**：新增/编辑/删除，标题、用户名、密码、网址、分组、标签、备注、收藏；密码可显隐，编辑时实时强度评估。
- **密码历史**：改密码时旧值自动留档（最近 5 条），可单条复制或清空。
- **搜索与分组**：标题/用户名/网址/备注/标签全文过滤；全部 / 收藏 / 未分组 + 自定义分组，计数实时联动。
- **拖拽**：拖动帐号排序，拖到左侧分组即移动；拖动分组可排序。
- **生成器**：长度 8–64、大小写/数字/符号开关、排除易混淆字符（`Il1O0o`）、CSPRNG + 拒绝采样（无取模偏差）、保底每类字符；生成配置可存为默认。
- **导入导出**：加密包（密文 JSON，可跨机迁移，需原开门密码）、明文 JSON、CSV（含中文表头识别）；导入支持合并（按「标题+用户名」去重）或清空后导入。导出明文/CSV 前需再次验证开门密码。
- **剪贴板**：复制用户名/密码写入系统剪贴板，默认 20 秒后自动清空（仅当剪贴板仍是本次写入的值时才清，不覆盖你随后复制的东西）。
- **自动锁定**：默认 5 分钟无操作锁定，可关/1/5/10/30/60 分钟；可选「切换到其它窗口立即锁定」。
- **快捷键**：`Ctrl+U` 复制用户名、`Ctrl+P` 复制密码、`Ctrl+N` 新增、`Ctrl+K` 搜索、`Ctrl+L` 立即锁定、`↑/↓` 选择、`Enter` 编辑、`Esc` 取消/关闭。
- **明暗双主题**，与仓库其它插件同一套 design token，选择记忆在插件私有存储里。
- **自绘下拉 & 动效**：排序/分组/自动锁定等全部下拉都是自绘组件（原生 select 的下拉面板是系统画的，无法与暗色玻璃风格统一），并配有入场/退场/反馈动效，细节见下节。

## 结构（`0.1.0/`）

- `index.html`（结构）+ `style.css`（样式）+ `app.js`（页面接线：渲染/交互/快捷键/自动锁定/剪贴板/导入导出）
- `ui.js` — 自绘下拉框组件：原生 `<select>` 的下拉面板由系统绘制、CSS 管不到（深蓝高亮、方角），这里把它降级为「取值真源」并盖一层自绘按钮 + 弹层，键盘 ↑↓/Home/End/Enter/Esc 与 `aria-*` 齐全；已接管实例的 `value` 访问器，所以 `$(id).value = x` 的调用点无需改动
- `crypto.js` — 密码学底座：AES-256-CBC + PKCS7、SHA-256、UTF-8/base64/hex、CSPRNG、定长比较；核心机械抽取自本仓库 `dev-toolbox/0.1.0/engine/{cipher,crypto}.js`，只保留用到的算法
- `vault.js` — 数据层：保险库模型、密钥派生、加解密、增删改查、分组、搜索、生成器、导入导出、存储适配（`spark.db` 优先，无宿主时回落 `localStorage`）
- `bcrypt.js` — bcryptjs 2.4.3（UMD），见 [VENDORS.md](0.1.0/VENDORS.md)

## 动效

界面动效都走同一套 token（`--dur-*` / `--ease-*`）：

- **入场**：建库/解锁/主界面切换时整屏轻淡入；列表在「整批换掉」的场景（切分组、切排序、保存、导入）按 `--i` 阶梯入场，**逐字搜索不播**（否则每敲一下整列表都闪）；空态与详情面板各自淡入。
- **退场**：侧滑面板、遮罩、对话框先播退场再隐藏（原来是直接消失）；对话框多步流程间内容切换淡入。
- **反馈**：复制成功对勾弹一下、生成器换一个时结果洗底一闪、分组选中项左侧指示条滑入、下拉框箭头旋转与选项高亮位移。
- **主题切换**：给主要表面挂颜色过渡（放在组件规则之前，自带 `transition` 的组件整条覆盖它，不会打乱已调好的 hover 动效）。
- 全程受 `prefers-reduced-motion: reduce` 兜底（系统开启「减少动态效果」后所有动画归零）。

## 测试

```bash
node password-manager/tests/vault-test.mjs   # 42 项：SHA-256/AES-256-CBC/bcrypt 标准向量 + 保险库端到端
node password-manager/tests/ui-smoke.mjs     # 69 项：真实 Chrome 无头 + CDP 走完整用户路径（含截图）
node password-manager/tests/icon-test.mjs    # 9 项：图标光栅化后量包围盒，校验四边留白对称
```

- 密码学正确性以公开测试向量为准：SHA-256 对 NIST FIPS 180-4，AES-256-CBC 对 NIST SP 800-38A F.2.5，并与 Node/OpenSSL 逐字节交叉验证随机 300 组；bcrypt 对官方已知答案向量。
- 数据层覆盖：错误密码/篡改密文/坏 PKCS7 均被拒绝，改开门密码后旧密码失效且数据不变。
- 界面冒烟覆盖：建库 → 新增 → 复制 → 搜索 → 分组 → 生成器 → 导出 → 锁定 → 解锁还原 → 快捷键，零未捕获异常。
- 图标自检把 SVG 光栅化成像素算白色图形的包围盒：居中偏差 ≤0.8、上下左右留白对称、四周留白 ≥4、图形占底板宽度 ≥60%（第一版就是纵向偏高 4.6/64，肉眼只觉得「有点怪」）。
