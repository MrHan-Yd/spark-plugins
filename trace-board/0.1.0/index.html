数据源库

点击顶部左侧的按钮打开数据源库：最近打开过的来源都在这里，本地与远程混在一起按标签区分， 置顶的排在前面。选过的会自动记住，下次开窗直接继续看。顶栏搜索框（按 / 聚焦）全局过滤笔记。

本地目录「选择项目目录…」选项目根即可，不需要授权。目录句柄会记住（IndexedDB），刷新后点一下直接重开；浏览器可能再弹一次授权，点允许即可。不支持句柄记忆的老内核才需要重选。
本地路径填绝对路径给 spark.fs 读，能记住并一键重开；需要先在 设置 → 插件 里授权该目录范围，否则报 PERMISSION_SCOPE。
远程库填 index.json 或 bundle.json 的完整 URL。
粘贴数据把导出的 JSON 直接贴进来，适合离线传阅与归档。

五个模块在回答什么问题

架构基线现在正在生效的东西：决策 KPI、承重墙（被引用最多的笔记）、领域架构分类阵列、生效的规则指纹、挂载的检查器与 agent 能力。有笔记时以笔记为主，没有时回落到文件改动视图。
演进时间线按日期铺开决策笔记与会话执行，左轨道点连线，支持月份与分类切片。
避坑智库被否决的笔记（❌放弃方案 / 💡权衡依据 / ✅采纳结果 三块）与运行时被拦的记录；「引用最多」= 同一目标被拦的次数。
决策清单全库决策笔记总表：编号 / 分类 / 标题 / 状态 / 日期 / 引用。没有笔记时回落为会话全表。
会话详情单会话深看：时间线（缩进即血缘，点方法名展开原始 JSON-RPC）、改动 Diff、合规自检、被否决。

术语

· 决策笔记：agent 按 AGENTS.md §4 写的决策知识（.agents/notes/），路径即状态即分类，文件名即锚点。
· 反向 RPC：agent 主动向宿主发起的请求（fs.*、terminal.*、session/request_permission）。拦截能力全发生在这一侧。
· 回合（turn）：一次 session/prompt 及其引发的全部事件。
· 协议错误：方法名未登记或方向不符。
· 统计范围：会话详情左轨勾选的会话；默认全选，四个聚合模块按勾上的部分统计（左轨只在会话详情显示）。
