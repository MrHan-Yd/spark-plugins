# PDF 编辑器（com.spark.pdf-editor）· 像素级 UI 设计蓝图

> ui-designer 交付（2026-09-17）· 施工蓝本
> 心理模型：Word/WPS 的「文档画布」专注感 × Figma/Notion 的「上下文面板 + 微动效」现代语汇，重构而非复刻。
> 技术底座契约假设见 §0；所有尺寸为逻辑像素（WebView2 DPR 缩放前的 CSS px）。
> 决策笔记：[2026-09-17-pdf-editor-design](../../.agents/notes/proposed/architecture/2026-09-17-pdf-editor-design.md)

## 0. 与架构的契约假设（冲突已裁定，见 A4）

| # | 假设 | 对 UI 的影响 |
|---|------|-------------|
| A1 | pdf.js 每页渲染为独立容器 `.pdf-page`（内含 canvas + 文本层 + 覆盖层三层叠放），页面间以 16px 间距纵向流式排列于画布滚动区 | 布局 §1、z 序 §5 直接按此结构给 token |
| A2 | 缩放采用两段式：「手势期 CSS transform 即时缩放 + debounce 落定后高清重渲、canvas 无闪替换」 | 缩放交互（§4.3）无需等待动画；UI 侧不做缩放过渡动画 |
| A3 | 覆盖元素数据模型以 pt（未旋转 PDF 用户空间）存储；UI 不持久化，编辑操作以「命令」提交架构层，撤销/重做栈由架构管理 | 状态栏只读「未保存/保存中/已保存」三态；Ctrl+Z 语义由架构保证，UI 只发键事件 |
| A4 | **（已裁定）** pdf.js 文本层（textLayer）在 P0 不启用（架构 R2：CJK 字体下文本层坐标偏移，不可依赖）。因此 P0 阶段：浮动工具条服务于**覆盖元素选中**与「点原文建白盒」后的预填文本框；**选中 PDF 原文文字就地浮现工具条**推迟到 P1 文本层开启后实现。P0 先交付浮动工具条的视觉与交互（在覆盖元素选区上验证），保证 P1 平滑升级 | §3.7 浮动工具条保留原设计规格，触发源在 P0/P1 间切换 |
| A5 | 导出为 pdf-lib 覆盖式写入（原文内容不重写）；保存可能耗时（大文件 1~5s），需进度弹层 | §3.9 保存进度弹层的取消按钮依赖架构可中断（若不可中断则禁用取消按钮） |
| A6 | 页面拖拽重排是数据层「页序变更」，缩略图 DOM 重排 + 画布滚动锚定到目标页由架构协调 | §3.2 落点指示线 + §4.2 重排动效 |

## 1. 整体布局骨架

### 1.1 宽态（≥1200px）五区全展开

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ① 顶栏 h=48 ────────────────────────────────────────────────────────────────│
│ [◫ logo 24] 文件名.pdf ●未存   │ ◫开始 ◫文本 ◫图形 ◫页面 ◫视图 │ ↶ ↷ │ 保存▾ │ ─ │
├──────┬────────────────────────────────────────────────────────┬──────────────┤
│ ②    │ ③ 文档画布（滚动区，画布底色 + 网点纹理）                │ ④ 属性面板    │
│ 页面 │  ┌─横标尺(可选,22px)────────────────────────────┐      │ w=280 常驻    │
│ 缩略 │  │   ┌──────────────┐                          │      │              │
│ 图    │  │   │  PDF 页面     │ ←浮起纸张 + 页码徽标      │      │ 无选中时：    │
│ 导航  │  │   │ canvas(L0)   │                          │      │  「页面」属性 │
│ w=208│  │   │ 文本层(L1)   │ ←选中框/8向柄             │      │ 有选中时：    │
│      │  │   │ 覆盖层(L2)   │                          │      │  元素属性     │
│ 拖拽 │  │   └──────────────┘                          │      │              │
│ 重排  │  │   ↕ 页间距 16px                             │      │              │
│ +插入 │  └───────────────────────────────────────────────┘     │              │
├──────┴────────────────────────────────────────────────────────┴──────────────┤
│ ⑤ 状态栏 h=26： 第 3 / 12 页  │ 缩放 − 100% ＋ │ ⇔适应 │ 已保存 14:32 │
└──────────────────────────────────────────────────────────────────────────────┘
```

**核心现代化决策**：顶栏 = 「模式 Tab + 上下文工具组」同层融合，砍掉 Word 的三行 ribbon。五个 Tab（开始/文本/图形/页面/视图）本身就是工具分组，Tab 切换时 Tab 右侧的工具按钮组交叉淡换（§4.1），全局面板（撤销/保存）恒在右侧。单行 48px，比 Word 省 60% 垂直空间。

### 1.2 各区职责与尺寸/伸缩策略

| 区 | 尺寸（宽态） | flex 策略 | 职责 |
|----|-------------|-----------|------|
| ① 顶栏 | h 48px，全宽 | `display:flex`；logo+文件名固定宽弹性截断（min 120px，`text-overflow:ellipsis`）；工具组居中弹性；右侧动作固定 | 模式切换、上下文工具、全局撤销/重做/保存、窗口关闭 |
| ② 缩略图栏 | w 208px（缩略卡 176px 宽，A4 比例高 ~249px） | 固定宽；可折叠至 56px 竖条态 | 页面导航、拖拽重排、插入/删除/旋转页；顶部搜索框按页码定位 |
| ③ 文档画布 | 弹性占满 | `flex:1; overflow:auto; scroll-behavior:auto`（缩放锚定需即时滚动，禁平滑） | 页面渲染 + 覆盖编辑 + 可选标尺/参考线；拖入 PDF 文件打开 |
| ④ 属性面板 | w 280px（含 16px 内距） | 固定宽；无选中且用户未钉住（pin）时整栏滑出（w→0）；窄态转为底部抽屉 | 选中元素的字体/字号/颜色/描边/透明度；无选中时显示当前页属性（旋转/尺寸） |
| ⑤ 状态栏 | h 26px，全宽 | 固定 | 页码（点击输入跳页）、缩放控制、保存状态 |

### 1.3 响应式三档（`spark.onResize` 驱动断点）

| 断点 | 布局降级 |
|------|---------|
| **宽 ≥1200** | 全展开；属性面板无选中时显示「页面属性」而非收起；缩略图 208px |
| **中 720–1199** | 属性面板转为「选中即滑入 264px / 取消选中即滑出」上下文态（默认收起）；缩略图收为 **56px 竖条**：仅显示迷你缩略（48px 宽）+ 页码数字，悬停整条时临时展开为 200px 覆盖抽屉（`position:absolute` 浮于画布上，阴影档②，移出 300ms 后收回）；标尺默认关闭 |
| **窄 <720（min_width=720）** | 缩略图竖条隐藏，以左缘 **32px 悬浮把手**（半胶囊，悬停滑出覆盖抽屉）替代；属性面板转为**底部抽屉**（高 224px，可上拖至 320px，下拉关闭）；顶栏工具组溢出进 `⋯` 菜单（保留前 4 个高频钮） |

插件 `window` 配置：`width 1280 / height 860 / min_width 720 / min_height 520`。

## 2. Design Tokens（像素级，亮/暗双主题）

### 2.1 主色拍板与理由

**主色：青碧 Cyan（亮 `#0E7490` / 暗 `#22D3EE`）**。理由：(a) 已扫全仓 14 插件，色相占用为橙/靛蓝紫/蓝/薄荷绿/紫/玫红/正蓝，青碧是唯一空位；(b) 刻意避开 pdf-toolkit 的玫红 `#e11d48`——同为 PDF 家族但错开色相，避免「全家桶式同脸」；(c) 青碧的语义是「墨水、精准、冷静」，恰好是编辑器的人格，且在白纸画布上，青碧选中框对黑字/彩图 PDF 内容的区分度高于蓝紫系；(d) 暗色 `#22D3EE` 在深灰底上明度足够做焦点环，无需加白。

## 3. 组件视觉契约

### 3.1 顶栏模式 Tab + 工具组

结构：`[logo 24×24] [文件名 13px ·●未存点 6px 圆 warn 色] ···居中··· [Tab×5] [工具组] ··· [↶ ↷ 32px 图标钮] [保存▾ 64px 主按钮] [─ 32px]`

- **Tab**：高 36px（顶栏 48 内上下留 6），内距 12px，图标 18px + 文字 14px/500，间距 8，圆角 8。
- **工具组**：紧随 Tab 右侧 12px，随 Tab 切换交叉淡换（§4.1）；组内图标钮 32×32（图标 20px），分组间以 1px `--line-1` 竖线分隔（上下距 8）。
- 状态矩阵（Tab 与图标钮通用）：

| 状态 | 视觉 |
|------|------|
| Default | 文字/图标 `--text-2`；底透明 |
| Hover | 底 `--bg-hover`，文字 `--text-1`，**无位移**（工具区不做上浮，保持工作台稳重） |
| Active/Pressed | 底 `--bg-active`；图标钮额外 `scale(0.94)`（60ms） |
| Active/选中（Tab 激活 / 切换开关型工具钮开启） | Tab：底 `--accent-soft` + 文字 `--accent` + 2px 主色下条（宽 20px 居中，bottom 4）；开关钮：底 `--accent-soft` + 20px 图标换主色 + 1px `--accent-border` 描边 |
| Focus | §2.6b 焦点环 |
| Disabled | 文字/图标 `--text-3`，底透明，cursor:not-allowed |
| 开关钮开启时的 Disabled | 保留 `--accent-soft` 底但图标降为 `--text-3` |

### 3.2 缩略图卡片

- 尺寸 176×249（A4 比 1:1.414），圆角 6，常态描边 1px `--line-1`、投影档①（比画布纸面弱 25% 透明度）；卡片间距 12px；页码徽标：左上角 18×18 圆角 4、底 `--bg-panel` 90%、字 `caption`/`font-mono`、选中页变主色底白字。
- 当前页：主色描边 1.5px + `--accent-soft` 外晕 3px；悬停未选中：描边 `--line-2` + 投影档①。
- 卡片底部 hover 时浮现迷你操作排（24px 高，居中，底 `--bg-raised`/85% 胶囊）：插入＋ / 旋转 / 复制 / 删除 4 个 20px 图标钮，间距 2。
- 状态矩阵：

| 状态 | 视觉 |
|------|------|
| Normal | 见上 |
| Hover | 描边加深 + 操作排淡入（120ms） |
| **拖拽中（被拖卡）** | 原位留 40% 透明「幽灵」；拖起副本 `scale(1.04)` + 投影档② + `rotate(1.5deg)`，跟随光标 |
| **落点指示线** | 2px 主色圆头线（高与卡同高，两端 6px 圆点），插入缝两侧卡片让位：前卡右移 4px / 后卡下移 4px（120ms 弹性 §4.1 spring） |
| Drop 落位 | 副本以 180ms spring 吸附落位，幽灵淡出 |
| 不可落（拖到自身相邻缝） | 指示线变 `--text-3` 虚线 |

### 3.3 文档页容器

- `.pdf-page`：宽随缩放（基准 A4 595pt），底 `--page-face`，圆角 2，投影档①，页间垂直距 16px；页右上外挂页码徽标（20px 高胶囊，`caption`+mono，底 `--bg-app` 75% + blur(6px)）。
- 页面加载占位：同尺寸骨架块（`--bg-app` 与 `--bg-canvas` 间色 shimmer，1.2s 循环）。
- 覆盖元素默认样式（与 PDF 内容可区分）：底 `--overlay-fill` + 描边 1px `--overlay-border` + 圆角 3 + 元素左上 14×14 主色小标（类型图标 10px）；悬停（非选中）：描边加至 1.5px；选中：见 §3.4。
- **可选标尺**：顶部/左侧各 22px，底 `--bg-panel`/70% + blur(8px)，刻度 8px 小格/40px 大格，mono 10px 字，`--text-3`；拖参考线出标尺为 1px 主色虚线，落位后 35% 透明常驻。

### 3.4 覆盖元素选中框 + 8 向缩放柄（精确视觉）

| 项 | 规格 |
|----|------|
| 选中框 | 1.5px `--accent` 实线，圆角 3；框外 2px 处叠加 1px `rgba(accent,.25)` 外晕（即档③选中环） |
| 柄尺寸 | 10×10px；四角柄圆形（直径 10），四边柄方形 8×10 |
| 柄样式 | 底 `--page-face`，描边 1.5px `--accent`，圆角 2，投影档③；相邻元素重叠时柄 `z` 恒高于一切覆盖元素 |
| 柄悬停 | 放大至 13×13（100ms §4.1 out-expo）；角柄光标 nwse/nesw-resize，边柄 ns/ew-resize |
| 柄按下 | 中心点缩至 8×8 + 底变 `--accent-soft`（拖拽中保持），对侧锚点显示 6px 主色十字标记 |
| 旋转柄 | 无（页面内元素不做自由旋转，降低复杂度；页面级旋转在缩略图/属性面板） |
| 拖拽移动 | 元素本体 100% 跟手；接近页面安全边距（8pt 网格）时显示 1px `rgba(accent,.5)` 吸附参考线 + 距离数值标签（mono 10px，反色气泡） |

### 3.5 覆盖文本框编辑态（双击进入）

| 项 | 规格 |
|----|------|
| 进入 | 选中框 1.5px 实线 → 虚线框（1px `--accent` dash 4-3）呼吸（透明度 .6↔1，1.2s 循环）；框内 `caret-color: var(--accent)`，光标宽 2px |
| 框体 | 内边距 8px；底变纯 `rgba(255,255,255,.92)`（亮）/`rgba(20,23,28,.92)`（暗）——编辑中排除底色干扰；描边转实线 1.5px |
| 文字 | `--font-editor`，字号跟随属性面板；行高 1.45；文字色默认 `--text-1`（可改） |
| 越界滚动 | 框固定尺寸，内文超出时纵向滚动，滚动条 4px 圆头 `--text-3`/30%，hover 加深；底部渐隐遮罩 12px 提示有更多内容 |

### 3.6 右键菜单（自绘，页面加固保留自建菜单）

- 容器：min 宽 180px，`--bg-raised`，r-10，投影档②，描边 1px `--line-1`（暗态 `--line-2`）；内距 6px；菜单项高 32px、内距 12px、圆角 6，图标 16px + 文字 13px + 右侧快捷键 mono 11px `--text-3`；分隔线 1px `--line-1` 上下距 6；危险项文字/图标 `--err`。
- 三种上下文：画布空白（粘贴/全选/插入…）、PDF 文本（复制/高亮/加删除线，P1 文本层开启后）、覆盖元素（编辑/置顶层/删除）。出现：Fade+Scale `.96→1` 120ms out-expo，锚点上方 4px 出现。

### 3.7 浮动工具条（就地浮现——Word 类体验关键）

- **触发（P0/P1 分期，见 §0 A4 裁定）**：P0 = 覆盖元素选中或白盒预填文本框出现时，于其上方浮现；P1（文本层开启后）= 选区非空且鼠标释放后 80ms 出现。位置 = 选区 rect 上方中点 −36px（含 8px 间距），越出画布顶部则翻转到下方 +8px，左右 clamp 于画布内 12px。
- **形态**：胶囊 r-full，高 36px，内距 6px，投影档②，底 `--bg-raised`/92% + blur(10px) + 1px `--line-2` 描边；出现动效 Fade + translateY(4px→0) + scale(.95→1) 140ms out-expo。
- **内容**（间距 2px，钮 28×28 圆角 6）：字体名（≤88px 截断下拉）｜字号步进 ▾▲｜**B** *I* U̲ S̶｜色点（14px 圆，当前色带白描边）｜高亮 ▾｜删除线式「删字」｜⋯ 更多。
- 状态：钮 Hover 底 `--bg-hover`；激活型（B/I/U）开启时底 `--accent-soft` 图标 `--accent`；选区取消后 120ms 反向淡出。
- 与右键菜单并存：浮动条优先（就近原则），右键仍可用。

### 3.8 属性面板（右侧，w 280 含 16 内距）

- 分组标题 `title-s`，组间分隔线；标签左、控件右的两列布局（标签 12px `--text-2`，右列 156px）。
- **分段选择器**（对齐方式/线型等）：胶囊容器底 `--bg-active`，r-full，内距 3，段钮 28×26；选中段底 `--bg-raised` + 投影档①微缩版（`0 1px 3px rgba(15,23,42,.14)`），图标 `--text-1`——即 iOS 风格滑块；切换时选中块 160ms out-expo 平移。
- **色板**：8 个 20px 圆点（主色系 5 + 黑/白/透明格纹），间距 6；当前点外环 2px `--accent` offset 2；尾部 `+` 打开自定色（HSL 面板弹层，另存于 spark.db）。
- **字号步进器**：30px 高输入框（mono 13px 居中）+ 两侧 24px ▾▲ 钮；步进 [8,9,10,11,12,14,16,18,20,24,28,32,40,48,64]；长按加速（首延迟 400ms，重复 60ms）；输入非数字失焦回弹。
- 透明度：滑杆（轨道 4px 圆头，填充主色，拇指 14px 白底主色描边）+ 数值 mono。
- 无选中态：显示「页面」组（旋转 90° 钮、页面尺寸只读 mono）+「本页操作」（插入页/删除页）。

## 4. 微交互与动效契约

### 4.1 全局曲线与时长

| Token | 曲线 | 用途 |
|---|---|---|
| `--ease-out-expo` | `cubic-bezier(0.16, 1, 0.3, 1)` | 面板/弹层/工具条出现（先快后缓，现代感主曲线） |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 缩略图落位、开关吸附（轻微过冲） |
| `--ease-std` | `cubic-bezier(0.4, 0, 0.2, 1)` | 退出与中性过渡 |

| 交互 | 时长/曲线 |
|---|---|
| Hover 着色 | 100ms out-expo |
| Pressed 缩放 | 60ms std（scale .94~.97） |
| 浮动工具条/右键菜单出现 | 120ms out-expo（fade+scale .95） |
| 属性面板滑入/滑出 | 220ms / 180ms out-expo |
| 弹层 | 入 200ms / 出 150ms |
| Toast | 入 240ms / 出 180ms |
| 缩略图让位与落位 | 120ms std / 180ms spring |
| 选中框出现 | 100ms out-expo（柄从 .6 scale + fade 同步入） |
| 双击进入文本编辑 | 框体无位移动画，仅描边态切换 80ms + caret 出现 |

### 4.2 拖拽重排视觉反馈链

按下（80ms 长按或直接拖 6px 位移阈值）→ 卡片「抬升」（scale 1.04 + 档②影 + rotate 1°）→ 拖动中落点指示线以 spring 让位邻居 → 释放落位 180ms spring → 全程画布滚动区自动跟随（缩略图拖到列表边缘时 300ms 内渐进滚动）。页序变更后，画布平滑滚动锚到目标页（240ms out-expo）。

### 4.3 缩放与滚动联动

- `Ctrl+滚轮`：以光标为锚缩放（0.25~4.0，步长 1.15 倍率），**即时生效无动画**（A2 两段式）；状态栏缩放数值 mono 滚动翻牌（120ms）。
- `Ctrl+0` 适应页宽 / `Ctrl+1` 100%：滚动位置补间 240ms out-expo。
- 普通滚动：无平滑（PDF 连续阅读要跟手）；跨页时状态栏页码即时更新。

### 4.4 操作可发现性策略（「不烦人」三原则）

1. **一次引导，永不重复**：首次成功打开 PDF 后，画布内出现 3 步 coachmark（半透明遮罩 + 高亮圈 + 反色气泡，可点「跳过」）——①点选页面元素看浮动工具条 ②双击文本框进入编辑 ③左侧拖动缩略图排序；完成或跳过后 `spark.db` 写标记，永不再现。
2. **就地提示，用完即走**：不弹气泡墙；快捷键提示仅在用户**执行等价鼠标操作第二次**时出现一次（如第二次用按钮旋转页面时提示 `R`），2s 自动消失。
3. **模式自解释**：切到「文本/图形」Tab 时，若画布 3s 内无操作，画布顶部中央浮现一条 28px 幽灵条（`--tip-bg`/85%，13px）提示「在页面上拖拽以绘制文本框/形状」，操作后立即消失，同类提示每文件只出现一次。

## 5. 视觉层级与 z 序约定（可直译给架构）

画布滚动区内每页容器 `.pdf-page` 建立 `isolation: isolate` 的独立层叠上下文，层固定 z 序 + 按模式矩阵分配 `pointer-events`：

| 层 | z-index | 内容 | 默认 pe | 选择模式 | 文本编辑中 | 形状绘制中 |
|----|---------|------|---------|----------|-----------|-----------|
| L0 | 0 | pdf.js 渲染 canvas | `none` | `none` | `none` | `none` |
| L1 | 1 | pdf.js 文本层（P0 不启用；P1 开启仅用于复制） | — | P1 起 `auto`（供原生选区） | `none` | `none` |
| L2 | 2 | 覆盖编辑层（各覆盖元素 + 选中框/柄） | 元素 `auto`，空隙穿透 | 元素 `auto`（P1 起与文本选区并存：按下在 L1 则选文本，命中覆盖元素则选元素） | 编辑框 `auto`，其余 `none` | 绘制捕获层 `auto` |
| L3 | 3 | 浮动 UI（浮动工具条、柄、参考线、吸附标签） | `none`（内部钮 `auto`） | 同左 | 同左 | `none` |
| L4 | 4 | 页内临时捕获层（形状拖绘/元素拖动用，透明全页矩形） | 仅绘制/拖动期间 `auto` | — | — | `auto` |

- 全局 DOM：顶栏/侧栏/状态栏是画布的兄弟节点，天然位于画布层叠之上；弹层（modal/menu/toast/coachmark）挂 body 级，z 依次 100/110/120/130；遮罩 90。
- 两条硬规则：(1) L1 与 L2 的 pe 互斥由「编辑模式」状态机决定，禁止两者同时 `auto` 造成选区/点选争抢；(2) L3 一切浮动 UI 必须跟随缩放变换的逆变换定位（以页面容器为定位父级、用 pt→px 换算），确保缩放后工具条仍贴住选区。

## 5b. 图标选型

内联 SVG `<symbol>` sprite（离线硬约束，禁 CDN/字体图标）：几何线性风格（1.5px 描边、round 线帽/交点、20px 网格，工具栏绘制 18px，缩略图/菜单 16px），自绘 40~50 枚子集（文件/页操作/文本样式/形状/缩放/撤销等），`currentColor` 传色；语义色仅 ok/warn/err 三类固定，其余跟随文字色。品牌 logo 72×72 双色（主色墨滴 + 中性纸页）。

## 蓝图自检清单（施工验收要点）

- 窄态 720px：属性面板→底部抽屉、缩略图→悬浮把手、工具组→溢出菜单，功能零丢失。
- 双主题全部 token 成对给出，页面纸面在暗色下仍近白（纸感不变），画布与面板拉开两档明度。
- 覆盖元素默认样式（半透明青碧底+描边）与任何 PDF 内容在明暗两主题下均可区分；选中档③阴影三档与柄规格可直接换算 CSS。
- 全部动效可从 §4.1 三个曲线 token + 时长表直译；无一处依赖网络资源。
