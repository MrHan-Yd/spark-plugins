# Agent Note: 轨道时间线对齐参考站（月分组 + 每卡节点 + 日期药丸）
Status: implemented
Class: feature

## 背景
owner 拿参考站（write-notes-like-deepseek 工程决策看板）截图指名「时间轴学一下图二」。旧版演进时间线：按日分组、组头挂「YYYY-MM-DD · N 条」徽章、整组只有一枚节点圆点，卡片自身不带日期也无节点；会话卡的开始时刻是裸文本。

## 决策
- 分组粒度从「日」升到「月」：组头只报「YYYY-MM · N 条」，具体日期沉到每张卡第一行的日期药丸（笔记 = 日历图标 + 完整日期；会话 = 时钟图标 +「日 时:分:秒」）。新增 `--ic-cal` mask 图标 token，与既有 `--ic-*` 体系同构。
- 左轨每个条目挂一枚 12px 节点圆环，用 `.tl-item::before` 伪元素画圆（零额外 DOM）；组头保留一枚实心圆点 + 柔光圈做轨道起点。
- hover 从「右移 4px」改为「边框/节点提亮 + 阴影」：节点圆环挂在卡片伪元素上，整体位移会把节点一起带离轨线。
- 摘要截断从 2 行放宽到 3 行，贴近参考站的疏朗感。SPEC §7.3 模块表与 §7.6 视觉基线已同步改写。

## 放弃方案
保持按日分组、只给卡片补节点。它改动最小，但卡内药丸日期与组头日期完全重复，信息量为零；且长月里日徽章连排，参考站的疏朗感出不来。

## 代价与后果
收益：与参考站视觉语言对齐；节点密度即条目密度，扫读更快；月份切片与月分组语义一致。代价：同月跨日条目没有日级视觉分界，靠药丸日期区分；`ui-smoke` 的 `.tl-group` 断言语义从「日组」变「月组」（组数变少，断言本身仍成立）。验证：ui-smoke 90/90 + contract 13/13 + icon 15/15 全绿，锚点校验 0 失效。
