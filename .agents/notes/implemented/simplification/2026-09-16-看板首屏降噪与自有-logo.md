# Agent Note: 看板首屏不自动弹抽屉与自有 logo
Status: implemented
Class: simplification

## 背景

2026-09-16 评审反馈两处：① 参考站对齐改造后，`icon.svg` 沿用了参考站的「双轨+横档」构图——视觉资产撞了别人家的 logo；② 看板一打开就自动弹「数据源库」抽屉（`init()` 里库为空就 `openDrawer('library')`），首屏注意力被抽屉抢走，老用户每次开窗也躲不开。

## 决策

- **logo 换成自有的「三节点阶梯」构图**：白色阶梯折线是执行轨迹（左下走到右上），两个绿点（accent `#35d3a1`）是已落定的决策，右上琥珀点（warn `#f0b45f`）是当前刻度。三色全部对齐应用内语义令牌，与参考站构图零同源。
- **首屏不再自动弹抽屉**：空态页本就渲染「还没有载入数据源 + 打开数据源库」引导按钮（空态 CTA 与自动弹抽屉的引导目标同效），状态栏也有指引文案。删掉 `init()` 末尾的无条件弹抽屉，`restoreLibrary` 的「有最近来源就静默续看」不变。

## 放弃方案

- **保留自动弹抽屉**：最强理由是新用户零步骤直达添加流程，转化路径最短。仍然不用，因为空态 CTA 按钮达成同效引导、却不遮挡看板本体；而自动弹抽屉对所有开窗场景一刀切，用过的用户每次都要手动关一次，降噪收益覆盖面更大。
- **沿用参考站构图、只改配色**：最强理由是构图现成且成熟，省一次设计。仍然不用，因为构图同源是抄来的本质特征，改色改线宽都藏不住；且参考站是人工策展站，其品牌资产不属于本插件。

## 代价与后果

- 收益：首屏安静（空态引导按钮 + 状态栏文案兜底）、品牌资产自有、图标三色与应用令牌同源（此前 icon 绿与应用 accent 绿是两套）。
- 代价：新用户从「被动弹窗」变「主动点按钮」，多一次点击；`icon-test.mjs` 的构图断言随新设计重写（双轨镜像三断言 → 三节点阶梯五断言），后续再改图标必须同步这份断言；ui-smoke 对应断言改了两条。
- 连带：`.agents/notes/` 从 .gitignore 取消——真实决策笔记按 AGENTS.md §4 应与代码同批提交，`@see` 锚点指向它才不会在克隆后失效；mock agent 写入的两篇样例内容确定性，重跑不弄脏 git。
